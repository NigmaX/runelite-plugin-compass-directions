# Compass Directions

A RuneLite plugin that adds **E**, **S** and **W** to the minimap compass, next to the game's own **N**.

The letters turn with the compass, so they always point at the real directions. Each one is drawn the same way up as the game's N.

## Settings

| Setting | What it does |
| --- | --- |
| Draw N | Also draw an N (off by default because the game already shows one) |
| Letter color | Color of E, S and W |
| N color | Color of the N when *Draw N* is on |
| Font size | Size of the letters |
| Distance from center (%) | How far from the compass center the letters sit |
| Outline | Draw a black outline around the letters |

Works in fixed, resizable classic and resizable modern layouts.

## Running locally

```bash
./gradlew run
```
